# 2026-11-03 优化与功能增强记录

本次迭代在保持“100% 离线、零数据上传”的前提下，对文档库、页面管理、导出、性能与设置做了系统性优化，并补充了多项同类扫描产品的常用能力。

## 一、优化内容

### 1. 文档库
- 文档列表改为聚合查询，一次取回**页数与封面缩略图**，修复列表永远显示“0 页 / 无封面”的问题，避免 N+1 查询。
- 搜索增加 250ms 防抖，减少每次按键都触发数据库查询。
- 支持按最近修改 / 创建时间 / 名称排序，收藏始终置顶。
- 支持列表 / 网格视图切换，并记住用户选择。

### 2. 导出
- 导出文件重名时自动追加 `_2`、`_3`，不再静默覆盖历史文件。
- 多页文档导出 JPG / PNG / WebP 时**逐页导出**，不再只导出第一页。
- PDF 支持 **A4 / Letter / 按原图** 三种纸张尺寸；A4/Letter 会自动横竖切换、等比缩放并留白。
- PDF 增加“图片最大边长”设置，控制导出体积。
- Excel 导出复用 `TableParser`，按行列解析更稳定。
- 可搜索 PDF 默认关闭，避免首次导出时因整页 OCR 等待过久；需要时可在导出页开启。

### 3. 性能与内存
- **OCR 引擎懒加载**：RapidOCR 不再在 App 启动/首页 ViewModel 构造时加载模型，改为首次识别时初始化。
- **OpenCV 懒加载**：不再在 `Application.onCreate` 同步加载 native 库，改为首次使用图像算法时加载；加载失败自动走 Bitmap 兜底。
- OCR 输入统一限制到 2000px，显著减少推理时间与内存占用。
- 滤镜预览改为中等分辨率解码，避免大图 OOM；切换滤镜时取消旧任务。
- 页面序号改为 DAO 原子取最大 index，避免连续保存时的并发冲突。
- 删除页面后自动重排 index，保证页面顺序连续。

### 4. 正确性修复
- “我的”页面版本号改为读取 `BuildConfig.VERSION_NAME`，不再硬编码。
- 可搜索 PDF 文字层颜色由完全透明改为 alpha=1 的黑色：Skia 会优化掉全透明文字，导致 PDF 中没有可检索文字对象。
- 页面旋转/裁剪/翻转后清空旧的打码框与批注坐标，避免坐标错位。

## 二、新增功能

| 功能 | 说明 |
|---|---|
| 文档库多选 | 长按进入多选，批量删除（进回收站）、收藏、导出 PDF |
| 重命名 | 文档库菜单与文档详情页均可重命名 |
| 页面管理 | 拍照/相册追加页面、删除、上移/下移、顺时针旋转 90°、设为封面 |
| 整份文档批量 OCR | 文档详情页一键识别所有缺文字页面，带进度与失败统计 |
| 证件扫描 | 正反面分别选择，自动边缘检测 + 透视校正，合成一张 A4 页面 |
| 打码脱敏 | 黑块 / 马赛克两种笔刷，拖动框选后应用 |
| 系统打印 | 文档详情页调起 Android 系统打印服务，可打印为 PDF 或送打印机 |
| 备份 / 恢复 | 全部文档（含页面图片与 OCR 文本）打包为 zip；可从 zip 恢复到本机 |
| 设置中心 | 默认滤镜、图片导出质量、PDF 纸张、PDF 图片最大边长、保存后自动 OCR、回收站保留天数、主题 |
| 相机增强 | 闪光灯（关/自动/开）、九宫格、前后摄像头切换、点击对焦 |
| 回收站自动清理 | 按设置天数在打开文档库时自动清理过期文档 |
| 主题切换 | 跟随系统 / 浅色 / 深色 |

## 三、测试结果

- **JVM 单元测试**：29 项，全部通过。
- **Android 仪器测试**：40 项，全部通过（Android 14 / API 34 模拟器）。
  - 覆盖：启动冒烟、Room DAO 搜索/收藏/回收站、页面重排、A4 PDF 尺寸、备份恢复、证件合成、打码、可搜索 PDF 文字层、OCR、导出、格式转换。
- **手工冒烟**：完整走通「拍照 → 裁剪 → 滤镜 → 保存 → 文档详情 → 导出 PDF」，并验证多选、证件扫描、设置页面。
- **PDF 产物校验**：A4 页面 `MediaBox [0 0 595 842]`，可搜索 PDF 含 ToUnicode CMap 与文字内容流。

## 四、说明

- 本次迭代未引入任何网络权限或分析 SDK，继续保持完全离线。
- Release APK 在本地使用 debug keystore 签名仅用于自测；正式发布请使用项目既定的 release keystore。
- 在 x86 模拟器上 RapidOCR/ONNX 推理较慢；arm64 真机预期明显更快。
